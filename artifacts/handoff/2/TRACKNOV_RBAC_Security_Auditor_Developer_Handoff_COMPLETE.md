## CORE PRINCIPLE
Tracknov is enterprise compliance infrastructure. Backend authority is absolute.

## ROLE MODEL
Allowed roles only: L0, L1, L2, L3, L5.

## PROJECT ISOLATION
Every entity must resolve to project_id with mandatory RLS.

## AUTHORIZATION
All authorization must route through centralized capability engine.

## FRONTEND TRUST
Frontend is untrusted and cannot mutate workflow directly.

## AI SECURITY
AI is advisory-only and authorization filtering must happen before retrieval.

## AUDIT IMMUTABILITY
Audit logs are append-only and immutable.

## SIGNED URL ENFORCEMENT
Documents must use signed URLs with expiry.

## RATE LIMITING
Mandatory on login, AI, uploads, exports, workflow APIs.

## PRODUCTION BLOCKERS
Missing RLS, workflow bypass, public URLs, or AI leakage block deployment.

## ASSUMPTION POLICY
Developers must stop and ask for clarification if ambiguity exists.
