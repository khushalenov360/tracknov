# TRACKNOV -- PROJECT ADMIN (L3) UI HANDOFF

## 1. ROLE

Project Admin validates documents, assigns responsibility, controls
workflow, and submits stages.

## 2. USER FLOW

Login → Daily Summary → Start Reviewing → Global Validation Queue →
Review Screen → Continuous Loop → Stage Submission

## 3. ADD PROJECT

-   Enter Project Code
-   Add to workspace
-   Errors: Invalid / Already exists

## 4. DAILY SUMMARY

-   Priorities
-   Blockers
-   Activity Summary
-   Stage Readiness
-   CTA: Start Reviewing

## 5. PROJECT OVERVIEW

-   Project info + progress
-   Workload snapshot
-   Stage tabs
-   Credit table
-   CTA: Validation Queue

## 6. GLOBAL VALIDATION QUEUE

-   Columns: Priority, Project, Stage, Credit, Document, Owner, Status
-   Filters: Project, Stage, Credit
-   Priority: Rejected \> Mandatory \> Oldest \> Optional

## 7. REVIEW SCREEN

-   Document Viewer
-   Context Panel (all docs in credit)
-   AI Panel (summary, data, compliance)
-   Credit Progress Widget
-   Actions: Approve / Reject / Clarify

## 8. ASSIGNMENT

-   One user per document type
-   Mandatory assignment

## 9. STAGE SUBMISSION

-   All mandatory docs approved
-   No pending validations
-   Submit stage

## 10. RULES

-   No deletion
-   No bypass
-   No bulk approval
-   Full audit logs
