# Disclosure Guidelines
1. Do not execute destructive, brute force, or denial of service audits.
2. Report all issues directly to security@tracknov.com prior to public disclosure.
3. We operate a strict multi-tenant isolation policy. Accessing another tenant's submittal data is considered a high-severity incident.
