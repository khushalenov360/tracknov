# TRACKNOV — AI NATIVE UXUI ELIMINATION HANDOFF

## PURPOSE
Eliminate doom scrolling, feature dumping, dashboard clutter, architecture leakage, navigation overload, weak mobile UX, and non-operational rendering.

Transform Tracknov into an AI-native Certification Execution Operating System.

## CORE UX RULES

### ONE SCREEN = ONE PURPOSE
No screen may mix:
- analytics
- projects
- audit logs
- queues
- navigation
- assignments

### REMOVE IMMEDIATELY
- giant dashboard cards
- stacked widgets
- raw audit timelines
- repeated project sections
- oversized login hero sections
- endless scrolling layouts
- table-first operational screens
- workspace terminology
- infrastructure visibility

## NEW APPLICATION MODEL
PRIMARY:
- Copilot
- operational queue
- action execution

SECONDARY:
- pages
- forms
- analytics

## REQUIRED GLOBAL LAYOUT

LEFT:
- queues
- blockers
- approvals

CENTER:
- active workflow

RIGHT:
- persistent copilot

Copilot MUST remain permanently visible.

## MOBILE RULES

### LOGIN SCREEN
Show ONLY:
- logo
- email
- password
- login button

### MOBILE NAVIGATION
Bottom nav only:
- Home
- Queue
- Copilot
- Projects
- Alerts

## L0 UX
Contributor sees ONLY:
- upload queue
- rejected uploads
- clarifications
- AI assistance

## L1 UX
Workflow:
Queue → Review → Approve → Next

## L3 UX
Show ONLY:
- blockers
- approvals
- readiness
- escalations
- AI operational guidance

Remove:
- audit timelines
- runtime diagnostics
- duplicate project sections

## L5 UX
Only L5 may see:
- governance tools
- replay systems
- reconciliation
- runtime diagnostics

## COPILOT REQUIREMENTS
Copilot becomes:
- primary execution layer
- workflow orchestrator
- operational assistant

NOT chatbot sidebar.

## REQUIRED COPILOT ACTIONS
Examples:
- Assign review to Deepa
- Show blockers for CCIL
- Approve current review
- Generate submission pack

## QUEUE-FIRST UX
Every workflow:
Queue → Action → Next

NOT:
Navigation → Exploration → Discovery

## WORKFLOW COMPRESSION
All major workflows:
3 clicks maximum.

## PROJECT PAGE
Show ONLY:
- readiness
- blockers
- pending approvals
- missing uploads
- AI recommendations

Remove:
- raw workflow tables
- event dumps
- audit spam

## VISUAL RULES
Use:
- whitespace
- minimal cards
- strong hierarchy
- progressive disclosure

Avoid:
- dense layouts
- equal visual weight
- giant tables
- excessive borders

## PERFORMANCE UX
Target:
- <2 second perceived load
- realtime queue updates
- no page reloads

- AICommandBar
- FocusQueue

- MobileBottomNav

Frontend succeeds ONLY if:
- users instantly know next action
- no endless scrolling exists
- copilot becomes primary interface
- operational clarity becomes immediate
- mobile UX becomes frictionless

## FINAL TARGET
Tracknov must feel like:
- Linear
- Cursor
- Notion AI

for Certification Execution Operations.
